# Agent instructions

This repository is built from `SPEC.md`. Its requirements hold for the whole life of the product,
not just for the change you are making.

- Before changing anything, read `SPEC.md`, and the notes in `docs/` if there are any.
- Keep the requirements written down where the next session will find them: when you set up a
  folder, an owner, a limit or a contract, record it in `docs/decisions.md` (one line each).
- Before you finish, check your change against every requirement of `SPEC.md`, not only the
  feature you built: ownership, shared values defined once, contracts on both sides, no copies.
- Run the tests and keep them passing; add tests for what you build.
