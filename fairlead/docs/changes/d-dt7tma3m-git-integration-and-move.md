# Git integration and move

Adds git integration and restructuring: shallow clones never pass silently, generated-file conflicts are regenerated by `sync`, `.gitattributes` gains union merges for ledgers, and `fairlead move` moves files and scopes with an obligations diff, and deletes, demotes, detaches and merges scopes.
