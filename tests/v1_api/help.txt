Repository-local rules and context for agents

Usage: fairlead [OPTIONS] [COMMAND]

Commands:
  init     Scaffold the control file, agent block, ignore lines and baseline; plan first (R-CLI-012)
  check    Scan and report drift; never writes (R-CLI-021)
  sync     Write generated files, the baseline with --baseline, and the cache (R-CLI-025)
  new      Scaffold one authored item; never overwrites (R-CLI-028)
  context  Budgeted brief for an agent: a path, an ID, or the session start (R-CLI-032)
  explain  Unbudgeted depth on a file, an ID, a code or a topic (R-CLI-035)
  approve  Record or list human approvals; terminal-gated (R-CLI-037)
  move     Relocate files, folders and scopes; rewrites fairlead's own text only (R-CLI-040)
  seal     Close the open version: seal ready change docs, write the version file last (R-CLI-041)
  upgrade  Move a codebase one edition forward through an approved, plan-hashed transaction (R-CLI-042)
  help     Print this message or the help of the given subcommand(s)

Options:
      --root <DIR>          Codebase root; wins over FAIRLEAD_ROOT and the upward search (R-CLI-004)
  -C <DIR>                  Run as if started in DIR; the root search starts there (R-CLI-006)
      --format <FORMAT>     Output format: human, terse or json; sarif for check only (R-CLI-006) [possible values: human, terse, json, sarif]
      --quiet               Suppress informational output; errors still print
      --color <WHEN>        Colour: auto (TTY and NO_COLOR unset) or never (R-CLI-006) [default: auto] [possible values: auto, never]
      --as-of <YYYY-MM-DD>  Date for exp= and date expiry; default UTC today (D-37, R-CHK-014)
      --no-cache            Ignore the .fairlead/ cache; output stays byte-identical (R-CHK-013)
      --threads <N>         Worker threads; FAIRLEAD_THREADS sets the same value and the flag wins (D-54)
  -h, --help                Print help
  -V, --version             Print version

Start:      fairlead init --dry-run, then fairlead init --yes; fairlead check; fairlead context <path>
Learn:      fairlead explain syntax | kinds | approve | pr-template | docs-first | authority | <a diagnostic code from check>
Exit codes: 0 ok; 1 findings that fail the run; 2 usage, configuration or syntax error;
            3 stale generated files (run fairlead sync); 4 refused by a gate or a policy;
            5 internal error or cannot determine. When several apply: 5, 2, 4, 1, 3, 0.
