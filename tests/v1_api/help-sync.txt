Write generated files, the baseline with --baseline, and the cache (R-CLI-025)

Usage: fairlead sync [OPTIONS]

Options:
      --dry-run             Print the plan and write nothing; exit 0 (R-CLI-025)
      --root <DIR>          Codebase root; wins over FAIRLEAD_ROOT and the upward search (R-CLI-004)
  -C <DIR>                  Run as if started in DIR; the root search starts there (R-CLI-006)
      --yes                 Accepted and ignored: sync applies directly (R-CLI-043)
      --baseline            Write the baseline; prunes unless --accept-new is given (R-CHK-030)
      --format <FORMAT>     Output format: human, terse or json; sarif for check only (R-CLI-006) [possible values: human, terse, json, sarif]
      --accept-new          Add current findings to the baseline; needs --baseline and --why (R-CHK-032)
      --quiet               Suppress informational output; errors still print
      --color <WHEN>        Colour: auto (TTY and NO_COLOR unset) or never (R-CLI-006) [default: auto] [possible values: auto, never]
      --why <TEXT>          Reason recorded with accepted findings (R-CHK-032)
      --accept-vendor       Accept changed vendor-owned hashes (R-FILE-040)
      --as-of <YYYY-MM-DD>  Date for exp= and date expiry; default UTC today (D-37, R-CHK-014)
      --force               Overwrite a hand-edited generated file; the edit is quarantined first (R-CLI-026)
      --no-cache            Ignore the .fairlead/ cache; output stays byte-identical (R-CHK-013)
      --scope <ID>          Write only that scope's generated files (R-SCOPE-063)
      --threads <N>         Worker threads; FAIRLEAD_THREADS sets the same value and the flag wins (D-54)
      --purge <ID>          Reduce a record's ledger lines to `id + date + digest`, for an erasure request; git history is untouched (R-RET-043)
  -h, --help                Print help
