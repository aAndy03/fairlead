Record or list human approvals; terminal-gated (R-CLI-037)

Usage: fairlead approve [OPTIONS] [TARGET]

Arguments:
  [TARGET]  A 12-character fingerprint, or the ID of an item with a pending ovr (C-20)

Options:
      --as <@HANDLE>        Approver handle recorded on the approval (R-CLI-037)
      --root <DIR>          Codebase root; wins over FAIRLEAD_ROOT and the upward search (R-CLI-004)
  -C <DIR>                  Run as if started in DIR; the root search starts there (R-CLI-006)
      --list                List recorded approvals; read-only (R-CLI-037)
      --format <FORMAT>     Output format: human, terse or json; sarif for check only (R-CLI-006) [possible values: human, terse, json, sarif]
      --revoke <FP>         Revoke an approval by fingerprint (R-CLI-037)
      --quiet               Suppress informational output; errors still print
      --color <WHEN>        Colour: auto (TTY and NO_COLOR unset) or never (R-CLI-006) [default: auto] [possible values: auto, never]
      --as-of <YYYY-MM-DD>  Date for exp= and date expiry; default UTC today (D-37, R-CHK-014)
      --no-cache            Ignore the .fairlead/ cache; output stays byte-identical (R-CHK-013)
      --threads <N>         Worker threads; FAIRLEAD_THREADS sets the same value and the flag wins (D-54)
  -h, --help                Print help
