Budgeted brief for an agent: a path, an ID, or the session start (R-CLI-032)

Usage: fairlead context [OPTIONS] [TARGET]

Arguments:
  [TARGET]  A path (wins), an ID (explain lookup), or nothing for the session-start brief (R-CLI-032)

Options:
      --budget <N>                  Token budget; 0 is unlimited (R-CTX-044)
      --root <DIR>                  Codebase root; wins over FAIRLEAD_ROOT and the upward search (R-CLI-004)
  -C <DIR>                          Run as if started in DIR; the root search starts there (R-CLI-006)
      --scope <S>                   Pin one scope (R-CLI-032)
      --format <FORMAT>             Output format: human, terse or json; sarif for check only (R-CLI-006) [possible values: human, terse, json, sarif]
      --full                        Expand inherited rules (R-CTX-022)
      --depth <N>                   Index depth for a whole-tree L0 (R-CTX-071)
      --quiet                       Suppress informational output; errors still print
      --color <WHEN>                Colour: auto (TTY and NO_COLOR unset) or never (R-CLI-006) [default: auto] [possible values: auto, never]
      --digest                      Print only the effective digest (R-CTX-033)
      --as-of <YYYY-MM-DD>          Date for exp= and date expiry; default UTC today (D-37, R-CHK-014)
      --exact-tokens                Count with the configured tokenizer; exit 2 if none (R-CTX-043)
      --no-cache                    Ignore the .fairlead/ cache; output stays byte-identical (R-CHK-013)
      --since <VERSION|REV|DIGEST>  Only what changed since a version, a git revision or a digest (R-CTX-051)
      --dense                       A dictionary-aliased form of the terse brief, for very large L0 dumps; never the default, the dictionary comes first (R-CTX-034)
      --threads <N>                 Worker threads; FAIRLEAD_THREADS sets the same value and the flag wins (D-54)
  -h, --help                        Print help
